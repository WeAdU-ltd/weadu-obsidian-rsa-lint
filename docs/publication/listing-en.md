# Listing texts (English)

## Name

WeAdU RSA Lint

## Short description (manifest, 250 characters max)

Check Google Ads headline and description lengths, flag common issues, and recombine words you already typed into candidates. No model and no network.

## Long description

WeAdU RSA Lint checks responsive search ad lines while you draft them in Obsidian.

- Lint ad lines: select your lines and get, for each one, its width against the headline (30) or description (90) limit, plus flags for an exclamation mark in a headline, repeated punctuation, a phone number, a word in capitals, or a superlative such as "best".
- Build candidates from a brief: type a product, a benefit, an optional offer, and a call to action. The plugin recombines only those words into headline and description candidates and trims them to the limit at a word boundary. Nothing is invented.

Chinese, Japanese, and Korean characters count as two. The widths are a local approximation, not an approval from Google.

No AI model, no network request, no telemetry. Free and open source (MIT), made by WeAdU.
